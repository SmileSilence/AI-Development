# UE开发资产模板

本目录包含Unreal Engine开发的资产模板和示例。

## 可用资产

### 蓝图模板
- 基础Actor蓝图
- 游戏模式蓝图
- 玩家控制器蓝图
- UI控件蓝图

### 材质模板
- 基础PBR材质
- 透明材质
- 发光材质

### 项目模板
- 第一人称项目模板
- 第三人称项目模板
- 空白项目模板

## 使用方法

1. 将模板文件复制到项目的Content目录
2. 在UE编辑器中重新导入资产
3. 根据项目需求修改模板

## 自定义模板

要创建自定义模板：
1. 在UE编辑器中创建基础资产
2. 右键选择"资产操作" -> "导出"
3. 将导出的文件保存到本目录
4. 更新此README文件

## 注意事项

- 模板资产可能需要根据UE版本进行调整
- 确保模板资产的引用路径正确
- 定期更新模板以适应新版本UE
