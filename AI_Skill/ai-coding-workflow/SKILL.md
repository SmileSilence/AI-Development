# AI编码流程技能

本技能提供AI辅助编码的完整工作流程，帮助开发者高效利用AI工具进行软件开发。

## 触发条件

- 用户说「AI 帮我写代码」「用 AI 编码」「AI 辅助开发」
- 用户请求代码生成、代码审查、单元测试编写
- 用户说「ai-coding-workflow」或「AI 编码流程」

## 核心原则

- **明确需求**：清晰定义问题和期望结果
- **迭代优化**：通过多次交互逐步完善代码
- **质量保证**：始终验证AI生成的代码质量

## 工作流程

### 1. 需求分析
- 理解用户需求和业务背景
- 确定技术约束和性能要求
- 明确输入输出规格

### 2. 提示设计
- **具体明确**：提供详细的上下文和要求
- **分步骤**：将复杂任务分解为多个简单步骤
- **示例驱动**：提供输入输出示例
- **约束说明**：明确技术栈、性能要求等限制

### 3. 代码生成
- 使用AI生成初始代码框架
- 逐步细化和完善实现
- 保持代码模块化和可测试性

### 4. 代码审查
- **语法检查**：确保代码无语法错误
- **逻辑验证**：检查算法和业务逻辑正确性
- **性能分析**：评估时间和空间复杂度
- **安全审查**：检查潜在的安全漏洞

### 5. 测试验证
- 编写单元测试和集成测试
- 验证边界条件和异常情况
- 进行性能测试和压力测试

### 6. 迭代优化
- 根据测试结果调整代码
- 优化性能和可读性
- 重构和改进架构

## 最佳实践

### 决策和确认规则
- **设计部分**：架构设计、模块划分、接口设计等需要用户确认后再实施
- **bug修复**：直接修复bug，无需用户确认，但修复后需向用户报告修复内容和测试结果
- **优化结构**：代码重构、性能优化、结构调整等需要用户确认后再实施
- **报告机制**：所有操作完成后需向用户报告结果和影响
### 提示工程技巧
- 使用角色设定（如"资深Python开发者"）
- 提供代码上下文和项目结构
- 指定代码风格和规范
- 要求AI解释其推理过程

### 代码质量保证
- 始终验证AI生成的代码
- 不要盲目接受AI建议
- 保持对代码的理解和控制
- 结合人工审查和AI辅助

### 工具集成
- 与版本控制系统（Git）集成
- 使用代码质量检查工具
- 集成自动化测试框架
- 配置持续集成/持续部署（CI/CD）

## 常见场景

### 新功能开发
1. 需求分析和设计
2. AI生成代码框架
3. 人工细化和完善
4. 测试和验证

### 代码重构
1. 分析现有代码问题
2. AI建议重构方案
3. 逐步重构和测试
4. 验证功能一致性

### 调试和修复
1. 描述问题和错误信息
2. AI分析可能原因
3. 生成修复方案
4. 测试修复效果
