# SmileKnow-Collector — 个人知识收集器

用于收集、整理和检索用户在使用过程中遇到的问题、解决方案和查找方法，提炼出通用的工作方式和习惯，帮助构建和维护个人知识库。

## 功能

### 1. 记录问题
记录用户遇到的问题，包括：
- 问题描述
- 上下文环境
- 发生时间
- 相关标签

### 2. 记录解决方案
记录问题的解决方式，包括：
- 解决步骤
- 代码片段
- 关键要点
- 所用工具

### 3. 记录查找方式
记录查找问题的过程，包括：
- 搜索关键词
- 参考文档
- 使用的命令
- 排查思路

### 4. 查询与检索
支持多种查询方式：
- 按关键词搜索
- 按标签筛选
- 按时间范围查询
- 按类型（问题/解决方案/查找方式）筛选

### 5. 分析知识库
在整理之前先分析知识库状态，提供整理建议：

**分析内容：**
- **统计概览**：总记录数、各类型记录数、标签数量
- **重复检测**：识别内容相似或重复的记录
- **标签分析**：标签使用频率、冗余标签、缺失标签
- **质量评估**：记录完整度、解决方案覆盖率
- **分布分析**：按时间、类型、标签的分布情况
- **整理建议**：基于分析结果提供具体的整理建议

### 6. 整理与维护
对知识库进行整理和优化（基于分析结果）：
- **合并相似记录**：识别并合并内容相似的记录
- **删除重复项**：移除完全重复的记录
- **标签优化**：清理冗余标签，建立标签体系
- **分类整理**：按主题、技术栈、问题类型等进行分类
- **记录归档**：将过期或已解决的记录归档
- **知识库压缩**：优化存储结构，减少冗余

### 7. 提炼方式与习惯
从具体记录中提炼通用的工作方式和习惯：
- **模式识别**：识别重复出现的解决模式
- **方法提炼**：将具体解决方案抽象为通用方法
- **习惯总结**：总结常用的工作习惯和流程
- **工具整理**：整理常用工具和技巧
- **思维模式**：提炼解决问题的思维模式
- **删除具体实例**：删除具体记录，只保留提炼后的方式和习惯

### 8. 导出与总结
- 导出为Markdown文档
- 导出为JSON数据
- 生成常见问题总结
- 统计问题类型分布
- 生成知识库使用报告

### 9. 存储目录配置
支持自定义存储目录，实现灵活的数据管理：

**配置功能：**
- **首次运行配置**：第一次使用时询问用户希望存储的目录
- **目录设置**：设置数据存储目录和导出目录
- **目录迁移**：支持将现有数据迁移到新目录
- **配置查看**：查看当前存储目录配置
- **重置配置**：重置为默认目录

**主动提出修改目录：**
在以下情况会主动询问用户是否需要修改目录：
- **定期提醒**：每30天提醒用户检查目录配置
- **空间不足**：检测到目录空间不足时提醒
- **使用频繁**：当用户频繁使用技能时建议优化目录
- **操作触发**：在导出、整理等操作前询问
- **路径问题**：检测到目录权限或路径问题时提醒

### 10. 定时自动整理
支持定时自动分析和整理知识库，保持知识库持续优化：

**定时整理功能：**
- **自动分析**：定时分析知识库状态
- **自动整理**：根据分析结果自动执行整理
- **自动提炼**：定期提炼方式和习惯
- **静默执行**：整理完成后静默执行，无需通知用户
- **灵活配置**：支持自定义整理频率和内容

**定时整理配置：**
```json
{
  "auto_cleanup": {
    "enabled": true,
    "frequency": "weekly",
    "time": "02:00",
    "last_run": "2026-08-22T02:00:00",
    "next_run": "2026-08-29T02:00:00",
    "actions": ["analyze", "cleanup", "extract"],
    "notify": false
  }
}
```

**整理频率选项：**
- **daily**：每天整理一次
- **weekly**：每周整理一次（推荐）
- **biweekly**：每两周整理一次
- **monthly**：每月整理一次
- **custom**：自定义整理间隔

**整理内容选项：**
- **analyze**：分析知识库状态
- **cleanup**：整理和优化记录
- **extract**：提炼方式和习惯
- **export**：生成整理报告
- **archive**：归档旧记录

**静默执行模式：**
- 整理完成后不弹出通知
- 整理结果保存在日志文件中
- 用户可随时查看整理历史
- 减少对用户的干扰

### 11. 快速记录
支持快速记录功能，简化记录流程：

**快速记录模式：**
- **一键记录**：快速记录问题和解决方案
- **智能识别**：自动识别记录类型
- **自动标签**：根据内容自动推荐标签
- **快捷键支持**：支持快捷操作
- **批量记录**：支持批量添加记录

## 工作流程

```
0. 配置存储目录、定时整理和自定义关键词
   ↓
   设置存储位置、自动整理频率和快速调用关键词
   ↓
1. 记录问题和解决方案
   ↓
   收集知识（支持快速记录）
   ↓
2. 定时自动分析（静默）
   ↓
   了解当前状态、发现问题
   ↓
3. 定时自动整理（静默）
   ↓
   根据分析结果进行整理
   ↓
4. 定时自动提炼（静默）
   ↓
   从整理后的记录中提炼通用方法
   ↓
5. 生成整理报告（保存到日志）
```

## 数据存储

### 存储位置
数据存储位置通过配置文件管理：

**默认位置（未配置时）：**
```
SmileKnow-Collector/
├── data/               # 数据存储
│   ├── records.json    # 所有记录
│   ├── tags.json       # 标签索引
│   ├── methods.json    # 提炼的方式
│   └── habits.json     # 总结的习惯
├── exports/            # 导出文件
├── logs/               # 整理日志
├── backups/            # 备份文件
└── config.json         # 配置文件
```

**自定义位置（配置后）：**
```
用户指定的目录/
├── data/               # 数据存储
│   ├── records.json
│   ├── tags.json
│   ├── methods.json
│   └── habits.json
├── exports/            # 导出文件
├── logs/               # 整理日志
└── backups/            # 备份文件
```

### 配置管理
- **config.json**：存储在技能目录下，记录用户的目录配置和定时任务配置
- **首次运行**：自动检测是否为首次运行，引导用户配置
- **目录验证**：配置时验证目录是否存在、是否有写入权限
- **数据迁移**：支持将现有数据迁移到新目录
- **主动提醒**：根据使用情况主动提醒用户检查目录
- **定时任务**：配置和管理定时整理任务
- **整理日志**：记录定时整理的执行历史和结果
- **加密配置**：数据加密设置
- **关键词配置**：自定义快速调用关键词

## 配置详解

### 配置文件结构
```json
{
  "default_storage_dir": "D:/MyKnowledgeBase/data",
  "custom_export_dir": "D:/MyKnowledgeBase/exports",
  "first_run": false,
  "configured_at": "2026-08-22T18:00:00",
  "custom_keywords": {
    "enabled": true,
    "keywords": ["SmileKnow", "SmileKnowXXX"],
    "set_at": "2026-08-22T18:00:00"
  },
  "auto_cleanup": {
    "enabled": true,
    "frequency": "weekly",
    "time": "02:00",
    "last_run": "2026-08-22T02:00:00",
    "next_run": "2026-08-29T02:00:00",
    "actions": ["analyze", "cleanup", "extract"],
    "notify": false,
    "retention_days": 30,
    "max_records": 1000
  },
  "encryption": {
    "enabled": false,
    "algorithm": "AES-256",
    "password_hash": null,
    "auto_lock": true,
    "lock_timeout": 300
  },
  "quick_record": {
    "enabled": true,
    "auto_tag": true,
    "smart_detect": true
  },
  "backup": {
    "auto_backup": true,
    "frequency": "daily",
    "max_backups": 10,
    "backup_dir": "backups"
  }
}
```

### 配置参数说明

#### 基本参数
- **default_storage_dir**：默认数据存储目录
- **custom_export_dir**：自定义导出目录
- **first_run**：是否首次运行
- **configured_at**：配置时间

#### 自定义关键词参数
- **enabled**：是否启用自定义关键词
- **keywords**：关键词列表（默认包含SmileKnow和SmileKnowXXX）
- **set_at**：关键词设置时间

#### 定时整理参数
- **enabled**：是否启用定时整理
- **frequency**：整理频率（daily/weekly/biweekly/monthly）
- **time**：整理时间
- **last_run**：上次运行时间
- **next_run**：下次运行时间
- **actions**：整理操作列表
- **notify**：是否通知用户
- **retention_days**：记录保留天数
- **max_records**：最大记录数量

#### 加密参数
- **enabled**：是否启用加密
- **algorithm**：加密算法
- **password_hash**：密码哈希
- **auto_lock**：是否自动锁定
- **lock_timeout**：锁定超时时间

#### 快速记录参数
- **enabled**：是否启用快速记录
- **auto_tag**：是否自动标签
- **smart_detect**：是否智能识别

#### 备份参数
- **auto_backup**：是否自动备份
- **backup_frequency**：备份频率
- **max_backups**：最大备份数量
- **backup_dir**：备份目录

## 主动提醒机制

### 提醒触发条件

#### 1. 定期提醒
- **时间间隔**：每30天提醒一次
- **检查方式**：比较当前时间与上次配置时间
- **提醒内容**：显示目录使用情况，询问是否需要修改

#### 2. 空间不足提醒
- **检查方式**：检测目录所在磁盘的可用空间
- **阈值设置**：可用空间低于1GB时提醒
- **提醒内容**：显示空间使用情况，建议清理或迁移

#### 3. 使用频繁提醒
- **检查方式**：统计最近7天的使用次数
- **阈值设置**：7天内使用超过10次时提醒
- **提醒内容**：建议优化目录位置，提高访问速度

#### 4. 操作触发提醒
- **触发操作**：导出、整理、提炼等重要操作
- **提醒方式**：在操作前询问是否需要检查目录
- **提醒内容**：显示当前目录状态，询问是否继续

#### 5. 路径问题提醒
- **检查方式**：验证目录是否存在、是否有权限
- **问题类型**：目录不存在、权限不足、路径无效
- **提醒内容**：显示问题详情，引导用户修复

#### 6. 定时整理提醒
- **触发条件**：定时整理完成或失败时
- **提醒方式**：静默执行，不通知用户
- **查看方式**：用户可随时查看整理日志

#### 7. 备份提醒
- **触发条件**：超过7天未备份时
- **提醒内容**：建议创建备份
- **提醒方式**：在下次使用时提醒

#### 8. 关键词提醒
- **触发条件**：首次使用时未设置关键词
- **提醒内容**：建议设置自定义关键词
- **提醒方式**：在首次使用时提醒

### 提醒频率控制
- **避免频繁提醒**：同一类型的提醒24小时内只显示一次
- **用户偏好**：记录用户是否关闭了提醒
- **智能判断**：根据用户行为调整提醒频率

## 注意事项

1. **首次配置**：第一次使用时会自动引导配置存储目录、定时整理和自定义关键词
2. **主动提醒**：系统会根据使用情况主动提醒检查目录和关键词
3. **定时整理**：建议启用定时整理，保持知识库持续优化
4. **静默执行**：定时整理默认静默执行，不干扰用户正常使用
5. **查看日志**：用户可随时查看整理日志了解整理历史
6. **目录权限**：确保指定的目录有读写权限
7. **数据迁移**：更改目录时可选择是否迁移现有数据
8. **配置备份**：建议备份config.json文件
9. **路径格式**：使用正斜杠或双反斜杠，避免单反斜杠
10. **先分析后整理**：整理前先分析，了解问题再行动
11. **及时记录**：遇到问题时尽快记录，避免遗忘细节
12. **详细描述**：问题描述越详细，后续检索越容易
13. **合理标签**：使用有意义的标签，便于分类检索
14. **定期整理**：定期回顾和整理知识库，删除过时信息
15. **查看报告**：定期查看整理报告，了解知识库状态
16. **快速记录**：使用快速记录提高记录效率
17. **智能标签**：使用智能标签推荐简化标签管理
18. **数据加密**：敏感数据建议启用加密保护
19. **定期备份**：定期备份知识库，防止数据丢失
20. **多格式导出**：根据需要选择合适的导出格式
21. **自定义关键词**：使用SmileKnow或SmileKnowXXX快速调用技能
