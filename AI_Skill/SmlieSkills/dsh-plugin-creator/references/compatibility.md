# DSH 插件横向兼容性规范

约束**多插件共存**：开发新插件或修改既有插件时，不得改动到导致其他已安装插件功能无法使用。适用于可安装插件包与会话内动态插件两种形态。

## 核心原则

- **最小影响面**：只影响自有能力与界面，不触碰共享资源。
- **命名隔离**：所有对外标识（工具、服务、事件、插槽、样式）使用插件前缀。
- **先查后占**：注册前查询能力目录，发现占用不硬覆盖。
- **可回滚**：任何修改保留原版本与完整清理路径。

## 一、开发新插件时的兼容义务

### 1. 作用域隔离

- 不写全局变量，不挂 `window`；动态代码在自身 Plugin Fiber（插件运行作用域）内注册能力，停止或更新时自动移除。
- 样式使用 `styles.insert` 与主题 CSS 变量，且只作用于自有组件；不操作 `document.body`、`window` 或硬编码产品 DOM 选择器来替代插槽和主题接口。
- 组件内周期任务用 `React.useEffect(() => ctx.interval(callback, 1000), [])` 返回清理函数，不调用未提供的全局 `setTimeout`。

### 2. 命名前缀化

工具名、服务名、事件名、插槽键、样式类名、存储键等对外标识统一使用插件前缀（如 `<pluginId>-<name>`），避免与现有或未来插件撞名。

### 3. 占用检查（先查后占）

- 注册工具、服务或界面插槽前，先查询现有能力目录（`Tool.listTools`、`Builtin.listBuiltins`、插槽查询）。
- 发现占用时**不硬覆盖**；不要硬编码 `priority=-100` 作为通用覆盖方案（详见[故障定位](failure-atlas.md)）。改用更精确的插槽、协商改名或说明冲突。

### 4. 共享资源禁改

- 不修改共享配置、会话快照、全局 CSS 或其他插件的文件与资源。
- 监听共享事件时只读处理，不吞掉、不拦截事件，确保其他插件仍能收到。
- 依赖注入复用共享服务契约；扩展走窄范围扩展点，不替换共享服务。

### 5. 生命周期

`apply(ctx)` 注册的所有能力——事件、工具、界面、计时器、外部订阅——必须有受 Cordis 管理的清理路径；卸载后不留计时器、订阅、事件监听或界面插槽残留。

## 二、修改/调试既有插件时的兼容义务

- **只动目标插件**：不修改其他插件的代码、配置、资源。
- **回滚预案**：保留原版本以便回滚；修复失败版本时在原 Plugin 下定义新 Package，**不覆盖失败版本**（版本流程见[动态插件开发](cordis-dynamic.md)）。
- **影响面确认**：改动前明确受影响边界（共享服务、重叠能力、同主题界面），改动后逐一验证。

## 三、验证清单

- 变更后真实挂载/运行，重点核对与目标插件**有重叠能力、共享服务、同主题**的其他已装插件功能正常。
- 涉及共享事件或公共界面时，验证其他插件的事件接收与界面显示未受影响。
- 无宿主环境时只报告静态校验结果，不宣称运行验证通过。

## 四、常见破坏场景速查表

| 场景 | 破坏表现 | 正确做法 |
|------|----------|----------|
| 覆盖共享工具名 | 其他插件工具注册失败或被替换 | 查询 `Tool.listTools`，改名或协商 |
| 吞掉共享事件 | 其他插件收不到事件 | 只读监听，透传事件 |
| 操作 `document.body` | 破坏其他插件 UI 与布局 | 用插槽 + `styles.insert` |
| 修改共享配置 | 其他插件读不到或读到错误配置 | 只读引用，不改写 |
| 残留计时器/订阅 | 卸载后仍执行、报错 | 清理路径完整 |
| 硬编码 `priority=-100` | 抢占插槽导致其他插件失效 | 先查询精确插槽 |
| 覆盖共享服务契约 | 依赖该服务的插件功能异常 | 复用契约，扩展走扩展点 |
