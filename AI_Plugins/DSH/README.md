# DSH 插件

本目录管理 DeepSeek Harness（DSH）平台的插件资源。

| 文件夹 | 类型 | 用途 | GitHub 策略 |
|--------|------|------|-------------|
| `OtherPlugin/` | 第三方插件 | 保存下载的第三方插件源码及公开来源说明 | 源码和压缩包不上传，仅上传说明与清单 |
| `SmilePlugin/` | SmileXX 自有插件 | 保存自行创建和维护的 DSH 插件及相关工具源码 | 源码、文档和测试统一上传本仓库；构建产物与依赖不上传 |

新增插件时，应在对应分类下建立独立插件目录，避免把具体插件文件直接堆放在 `DSH/` 根目录。
