# SmileXX 自有 DSH 插件

本目录用于管理 SmileXX 创建和维护的 DeepSeek Harness 插件及相关工具。

## 项目索引

| 项目 | 类型 | 当前版本 | 功能 | 独立仓库 |
|------|------|----------|------|----------|
| ClaudeSettingsEditor | 配置管理工具 | 以项目仓库为准 | 可视化编辑 Claude Code 配置 | https://github.com/SmileSilence/ClaudeSettingsEditor |
| dsh-desktop | DSH 桌面客户端 | 1.1.1 | 为 DeepSeek Harness 提供 Windows 桌面体验 | https://github.com/SmileSilence/dsh-desktop |

以上项目在本地保留完整独立 Git 仓库，本仓库只上传索引，不重复上传源码或嵌套 `.git` 数据。新增无独立仓库的插件时，每个插件使用独立英文目录，并在本文件补充名称、版本、功能和发布状态。
