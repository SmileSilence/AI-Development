# 0.7.5 边缘流光修复报告

## 问题与修复

录屏中的流光在宽行中间错误拐弯，且底边轨迹被裁切。原因是 SVG 未声明宽高，Chromium 使用默认 `300×150` 画布，画布与实际长条行尺寸不一致。

边缘效果 SVG 现已显式设置 `width="100%"`、`height="100%"`，对应 CSS 也固定铺满装饰层。圆角矩形仍使用归一化周长与顺时针动画，基础颜色、速度和效果强度未改变。

## 验证

- 类型检查、10 个测试文件、127 项测试、构建、版本检查及打包检查通过。
- Microsoft Edge 实测：父行 `560×34`、效果层 `558×32`、SVG `558×32`。
- SVG 周长路径完整位于父行内，不再使用默认 `300×150` 画布。
- 页面运行期间无脚本错误。
- 日常 `web` 配置已安装并解析 `smilexx-workspace-enhancer 0.7.5`。

机器可读证据见 `browser-evidence.json` 与 `package-evidence.json`。
