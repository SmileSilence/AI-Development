# 0.7.0 实现说明

## 已实现

- 批量工作区和会话选择支持 Windows 风格的单选、Ctrl、Shift、Ctrl+Shift，以及列表内 Ctrl+A。复选框保留逐项增减；真实已挂载的可操作行构成选择范围，列表当前没有虚拟化。
- 分组、平铺、搜索共用选择状态逻辑，分类筛选按普通标签判断；列表变化后移除隐藏选择并重置失效锚点。批量期间行点击不跳转会话，不触发行拖拽。
- 独立运行状态标签支持启用、名称、底色、四种动效、主辅色和速度；设置草稿实时预览，保存后统一应用。自动协调色以空字符串持久化，随底色变化生成。
- 工作区悬停显示去重后的未归档、非空主会话数、原分类标签和运行状态数量；统计在筛选前计算。

## 接口与维护

- `WorkspaceTaggerSettings.runningTag` 是新配置；缺失或 null 时只读兼容旧 `runningTagId`，不会自动删除普通标签及绑定。独立设置保存后优先于旧引用。
- `TaggerController.saveRunningTag` 通过现有宿主设置作用域保存，订阅与失败传播沿用原控制器。
- `RUNNING_EFFECT_PRESETS` 集中声明预设标识、名称、样式和所需颜色数量。新增动效时同步类型、设置 schema（结构定义）、注册表和效果 CSS；无需修改各行组件。
- `TagSegment.effect` 使单色与双色胶囊复用效果层。双色仅后段应用动画；减少动态效果偏好下停止动画。
- 构建自动执行 `gen-css.mjs`，避免修改 CSS 后发布包注入旧样式。
